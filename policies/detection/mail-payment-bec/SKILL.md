# 付款与商业邮件诈骗

追踪付款主体、受益人及独立核验渠道。重点看个人代收、先缴保证金再退款、礼品卡兑换码、绕过双人审核、阻止回拨已登记联系人、历史邮件线程中突然变更账户。

发件人域名看似可信、旧邮件引用、盖章声明都不能替代流程证据。紧急催款或真实账户变更若仍要求已登记渠道核验和双人审批，不因这些词本身报风险。

明确绕过授权或交付可变现秘密可报 finding。依赖缺失合同、前文或账户信息的实际付款请求为 insufficient；信息充分且要求遵守既有流程为 no_finding。

借鉴 Sublime Rules 的组合证据和排除条件；不具备账户真实性或资金到账验证能力。
