# 远控、工作群与勒索检测

识别陌生群迁移、私下安装客户端、交付控制密码、解锁设备、共享网银或验证码、假续费后远程退款。核对是否要求绕过原群、采购、财务或既有服务台。

用户主动提交工单、从既有入口核实工程师并主动确认、使用预装工具且可随时结束，与未经核验的远控请求区别处理。

以曝光资料/视频威胁付款属于勒索诱导，即使邮件没有证明真的取得资料。结论只描述威胁请求，不把攻击者的占有声明作为事实。

只推荐已知渠道复核，不拨打邮件提供的号码或创建远控会话。
