# 误报与结论复核

对拟报告的风险明确回答：实际要求什么危险动作？哪段原文支持？正常业务解释是否已被上下文排除？结论是否仅来自关键词、陌生地址或附件类型？

特别检查否定句、培训反例、被转发的攻击、已知流程中的正常催款/重置/授权和无害隐藏摘要。正常内容提到危险动作，不等于正在要求收件人执行。

发现证据不充分时，先修正相应专项技能结论，再汇总最终结果。本复核通常返回 no_finding 并简述反证审查结果；确有无法解决且影响处置的缺失信息返回 insufficient。

最终 risk 需至少一个技能 finding 与原文证据；没有 finding 但存在 insufficient 时为 review；其他情况为 clear。clear 仅表示在现有证据和能力范围内未发现明显风险。

借鉴 Trail of Bits fp-check 的证据验证和反证审查思想；原技能面向代码漏洞，本技能是为邮件场景原创的迁移。
