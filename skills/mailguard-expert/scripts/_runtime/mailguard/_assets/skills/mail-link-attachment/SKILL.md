# 链接与附件检测

比较链接显示文字与实际 hostname；注意用户名段 @ 前的品牌不属于目标域名，内部域名出现在路径或恶意后缀的子域里不代表内部站点。同形字符和短链只能作为待核线索，不能声称已确认最终落地页。

关联用户被要求的动作：在陌生入口提交秘密、扫码付认证费、粘贴执行命令、启用宏、运行快捷方式/脚本、关闭防护、HTML/SVG 诱导下载。双扩展名与这些动作组合具有较强风险证据。

普通附件、压缩包、外链、UTF/域名编码本身不直接证明恶意。正常文档归档、已知入口及明确停止可疑操作的通知是重要反证。

看不到二维码像素、加密包内容或跳转后目标时，注明限制；必要信息缺失为 insufficient。只报告诱导与元数据事实，不声称检出了木马、执行链或确认附件安全。
